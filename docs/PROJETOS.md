Este é um mapa rápido dos arquivos do meu repositório. Eu sou estudante de Desenvolvimento de Sistemas no SENAI e estou aprendendo programação web. Alguns projetos são pequenos exercícios de aula; outros eu desenvolvi para experimentar ideias pessoais.

## ✦ Para conhecer primeiro

### 01. XQRENS · Meu portfólio

[Ver código do portfólio](../projetos/index.html)

O projeto que reúne minha trajetória, meus gostos, mangás, seções pessoais e trabalhos anteriores. Usei HTML, CSS e JavaScript para criar uma interface com capítulos, animações, temas e pequenas interações.

**O que pratiquei:** organização de uma página maior, responsividade, estilos visuais, eventos JavaScript e navegação.

### 02. Mente em Flor

[Ver código do Mente em Flor](../mente-em-flor/index.html)

Um site educativo pensado para conversar sobre saúde mental de um jeito acolhedor. Inclui dicas, uma pausa guiada, um check-in, sugestões para dias difíceis, ideias para conversar com alguém e caminhos para buscar apoio.

**O que pratiquei:** acessibilidade, componentes interativos, estados de interface, armazenamento local e organização de conteúdo.

> É um projeto educativo. Não faz diagnóstico, não oferece atendimento e não substitui profissionais de saúde.

## 💻 Testar no próprio computador

Com Python 3 instalado, execute a partir da raiz do repositório:

```bash
python -m http.server 8000
```

Depois acesse http://localhost:8000/projetos/ para o portfólio ou http://localhost:8000/mente-em-flor/ para o Mente em Flor.
